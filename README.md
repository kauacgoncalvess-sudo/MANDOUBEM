# MANDOU BEM — Protótipo Cliente V2

Versão demonstrativa da experiência do cliente.

## Novidades desta versão

1. Tela de login de entrada.
2. Segunda tela obrigatória para escolher 1 de 3 avatares.
3. Avatar acompanha o cliente na experiência.
4. Home mostra um resumo da jornada.
5. Recompensas agora aparecem como uma jornada em mapa, com ilhas.
6. Cada ilha possui um marco de pontos.
7. O avatar fica visualmente posicionado na ilha correspondente ao progresso.
8. Próxima ilha mostra quantos pontos faltam.
9. Estrutura preparada para que, no sistema real, o comerciante configure os marcos e recompensas pelo painel.

## Importante

Os valores das ilhas (1.000, 2.000, 3.500, 5.000...) são apenas exemplos do protótipo. No produto real, eles deverão vir do painel do comerciante e ser editáveis.

O login, banco de dados, pontos reais, autenticação, catálogo, pagamento e painel do comerciante ainda não estão conectados.
